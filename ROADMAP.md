# ROADMAP

Этапы разработки клона MECCHA CHAMELEON. Каждый этап опирается на предыдущий.

## MVP — рисование кистью + позы-пресеты + Infection ✅ (реализовано в первой итерации, код не тестирован вживую)

Цель: играбельный вертикальный срез, который можно протестировать вдвоём.
**Весь цикл написан в коде** (покраска + раунды + позы + обнаружение + очки +
свисток + Infection), но пока НЕ проверен в реальной Roblox Studio — это цель
следующего этапа.

- [x] Документация проекта (CLAUDE.md, README.md, ROADMAP.md, TASKS.md,
      CHANGELOG.md, DECISIONS.md, ARCHITECTURE.md)
- [x] Rojo-структура проекта (`default.project.json`, `src/...`)
- [x] Свободное рисование кистью по телу: "покрасочная камера", мазки
      (`Texture`-штампы) вдоль пути пальца/курсора, батчинг пакетов на сервер
      (см. DECISIONS.md, п.14 — механика пересмотрена после дополнительного
      изучения референса, раньше были кнопки выбора части тела)
- [x] Пипетка: raycast от камеры, чтение цвета поверхности
- [x] UI палитры цветов + слайдер размера кисти, адаптировано под мобильный экран
- [x] "Чернила" (расходуемый ресурс 0-100, тратится по площади мазка) вместо
      прежних дискретных "зарядов", восстанавливаются со временем
- [x] Базовая система ролей (Teams: Hiders/Seekers/Spectators)
- [x] Базовый автомат фаз раунда: Lobby → Hiding → Seeking → RoundEnd
- [x] Таймер раунда, синхронизированный через RemoteEvent
- [x] Поза - выбор из 4 конкретных пресетов (Crouch/LieDown/Lean/StandStill),
      каждый со своей анимацией-заглушкой и "hitbox-профилем" (HipHeight);
      только для Hiders и только в фазу Hiding (см. DECISIONS.md, п.17 —
      механика пересмотрена после дополнительного изучения референса, раньше
      была одна произвольная заморозка без выбора)
- [x] Обнаружение через ProximityPrompt **+ серверная проверка дистанции и
      line-of-sight**, подсказка видна только Seekers
- [x] Базовый подсчёт очков и экран результатов раунда
- [x] Свисток Hiders: автоматический каждые 45с в фазу поиска + ручной,
      сбрасывающий таймер (см. DECISIONS.md, п.15 — новая механика)
- [x] Режим Infection (по умолчанию): пойманный Hider не выбывает, а сразу
      становится Seeker - снимается поза, стирается покраска, меняется
      команда "на лету" (см. DECISIONS.md, п.18 — новая механика, режим
      Classic тоже заложен архитектурно, переключается одной константой)
