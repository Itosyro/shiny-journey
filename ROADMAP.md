# ROADMAP

Этапы разработки клона MECCHA CHAMELEON. Каждый этап опирается на предыдущий.

## MVP — базовая покраска + раунды ✅ (текущий этап завершён)

Цель: играбельный вертикальный срез, который можно протестировать вдвоём.

- [x] Документация проекта (CLAUDE.md, README.md, ROADMAP.md, TASKS.md,
      CHANGELOG.md, DECISIONS.md)
- [x] Rojo-структура проекта (`default.project.json`, `src/...`)
- [x] Система покраски: клиент шлёт запрос на сервер, сервер проверяет и красит
- [x] Пипетка: raycast от камеры, чтение цвета поверхности
- [x] UI палитры цветов + выбор части тела, адаптировано под мобильный экран
- [x] Лимит краски ("заряды кисти") с перезарядкой по времени
- [x] Базовая система ролей (Teams: Hiders/Seekers/Spectators)
- [x] Базовый автомат фаз раунда: Lobby → Hiding → Seeking → RoundEnd
- [x] Таймер раунда, синхронизированный через RemoteEvent
- [x] Базовая заморозка/поза (блокировка движения + анимация-заглушка)
- [x] Базовое обнаружение через ProximityPrompt
- [x] Базовый подсчёт очков и экран результатов раунда
