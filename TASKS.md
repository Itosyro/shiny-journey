## РАЗДЕЛ 0. Найденные при ревью проблемы

Список составлен в ходе аудита Opus (2026-07-05). Отсортирован по приоритету.
Помечены галочкой те, что **уже исправлены** в этом же ревью.

### Критичные (безопасность/краш)

- [x] **[КРИТ] Эксплойт `fireproximityprompt` в поимке.**
  `CatchService.lua` — серверный `Triggered` не проверял дистанцию, читер мог
  ловить всех Hiders с любой точки карты. → Добавлена серверная проверка
  расстояния (`seekerIsCloseEnough`) + настройки в `GameConfig`. Исправлено
  описание в `DECISIONS.md` п.4.
  ✔ Критерий: попытка "поймать" издалека серверно отклоняется.

- [x] **[ВЫС] Игровой цикл мог умереть навсегда от одной ошибки.**
  `RoundManager.gameLoop` — тело раунда не было изолировано. → Обёрнуто в
  `pcall` с аварийной уборкой и возвратом в лобби.
  ✔ Критерий: искусственная ошибка внутри фазы не вешает сервер, следующий
  раунд стартует.

- [x] **[ВЫС] Выход Hider посреди раунда ломал досрочное завершение.**
  `CatchService` не убирал вышедшего из `foundState`, поэтому `CountRemaining()`
  никогда не доходил до 0. → Добавлен `PlayerRemoving`-обработчик.
  ✔ Критерий: если один из трёх Hiders вышел, поимка двух оставшихся завершает
  раунд досрочно.

- [x] **[СРЕД] `JumpHeight` обнулялся при позе, но не восстанавливался.**
  `FreezeService` — на ригах `UseJumpPower=false` игрок навсегда терял прыжок
  после первой позы. → Кешируем исходные `walkSpeed/jumpPower/jumpHeight` и
  восстанавливаем.
  ✔ Критерий: после разморозки игрок прыгает как до неё.

### Дизайн-решения — приняты автором и внедрены (2026-07-05)

- [x] **[СРЕД, дизайн] Промпт поимки раскрывал позицию Hider.**
  Решение автора: подсказка видна **только Seekers** (Hiders её вообще не
  видят — скрывается персонально на клиенте через новый RemoteEvent
  `HideCatchPromptsFromHiders` + `CatchClient.lua`), имя убрано из текста
  (остался нейтральный `ActionText = "Поймать"`), включена
  `RequiresLineOfSight = true` **плюс** её же дублирующая серверная
  raycast-проверка в `CatchService.hasLineOfSight` (встроенное свойство —
  только клиентская проверка, обходится тем же эксплойтом, что и дистанция).
  См. `DECISIONS.md`, п.12.
  ✔ Критерий выполнен: Hider не видит подсказки над другими Hiders; Seeker не
  видит имени цели; поимка через стену/без прямого взгляда отклоняется
  сервером.

- [x] **[НИЗ, дизайн] Заморозка не была ограничена ролью/фазой.**
  Решение автора: вставать/выходить из позы может только Hider, и только во
  время фазы `Hiding` (не `Seeking`). Проверка добавлена в
  `FreezeService.onRequestFreeze` (роль + `RoundManager.State`), клиентская
  кнопка в `FreezeClient.lua` скрыта для Seekers и неактивна вне `Hiding`.
  См. `DECISIONS.md`, п.13 — там же зафиксирован сознательный компромисс:
  теперь Hider не может выйти из позы и во время `Seeking`, что убирает
  задуманную в исходном ТЗ механику "спалиться на движении при разморозке".
  Если захотите её вернуть — это одна строка условия в `FreezeService`.
  ✔ Критерий выполнен: Seeker не может встать в позу (сервер отклоняет,
  кнопка скрыта); Hider не может переключить позу в фазе `Seeking`.

### Не исправлено (более мелкое, не блокирует живой тест)

- [ ] **[НИЗ] Магические числа скорости (16/50) в двух местах.**
  `RoundManager.setWalkable` и дефолты в `FreezeService` хардкодят WalkSpeed/
  JumpPower. Вынести в `GameConfig`, а лучше — кешировать исходные значения
  Humanoid (как уже сделано для позы).
  ✔ Критерий: изменение скорости — в одном месте конфига.

## РАЗДЕЛ 0.5. Механика покраски пересмотрена на рисование кистью (2026-07-05)

Подробное обоснование выбора технологии (`Texture`-мазки вместо
`EditableImage`) — в `DECISIONS.md`, п.14. Также добавлена новая механика
свистка (`DECISIONS.md`, п.15), которой раньше не было в проекте.

  зарядов, приём и валидация пакетов точек мазка (`PaintStroke`), создание

  математика face/UV, используется и клиентом, и сервером.

- [x] `BrushControlsUIBuilder.lua` (новый) - слайдер размера кисти + кнопка
  входа/выхода в режим рисования.
- [x] `WhistleService.lua` (новый) - автосвисток каждые 45с в фазу Seeking,
  ручной свисток сбрасывает таймер, позиционный `Sound` с `RollOff`.
- [x] `WhistleClient.lua` (новый) - кнопка "Свистнуть" + индикатор обратного
  отсчёта, видна только Hiders в фазу Seeking.
- [x] `RoundManager.lua`/`Main.server.lua`/`Main.client.lua` - подключены новые
  сервисы, `ResetCharges` заменён на `ResetForNewRound` (стирает и чернила, и

## РАЗДЕЛ 0.6. Поза пересмотрена на конкретные пресеты + режим Infection (2026-07-05)

По прямому указанию автора: (1) поза была одной произвольной "заморозкой",
а должна быть выбором из конкретных пресетов с разным силуэтом, как в
оригинале; (2) пойманный Hider должен не выбывать, а сразу становиться
Seeker (режим Infection) - так устроен один из основных режимов оригинала.
Обоснование в `DECISIONS.md`, п.17 (позы) и п.18 (Infection).

- [x] `PosePresets.lua` (новый общий модуль, `ReplicatedStorage/Modules`) - 4
  пресета (Crouch/LieDown/Lean/StandStill), каждый с `animationId`,
  `hipHeightMultiplier` (hitbox-профиль) и заделом на будущее
  (`maskingBonus`/`poseChangeCooldownSeconds`, пока не используются).
- [x] `FreezeService.lua` переписан: валидация `poseId`, переключение позы
  прямо во время заморозки (останавливает старую анимацию перед новой),
  приоритет анимации повышен с `Action` до `Action4`, сохранение/
  восстановление `HipHeight` вместе с `walkSpeed`/`jumpPower`/`jumpHeight`.
- [x] `UI/PosePickerUIBuilder.lua` (новый) - карусель из 4 touch-friendly
  кнопок вместо одной кнопки "Заморозиться".
- [x] `FreezeClient.lua` переписан под карусель: гейтинг по роли/фазе теперь
  через полное скрытие панели (не `Active`, т.к. `Frame.Active` не блокирует
  клики по дочерним кнопкам - найдено и исправлено в процессе).
- [x] Явно проверена связь "поза блокирует рисование" (требование задачи) -
  подтверждено рабочей: `FreezeService.applyFreeze` вызывает `PaintService.
  SetPaintingAllowed(player, not wantsFreeze)`, `PaintService.onPaintStroke`
  проверяет этот флаг. Изменений не потребовалось, связь была корректной.
- [x] `GameMode.lua` (новый общий модуль) - `Classic`/`Infection`, по
  умолчанию `Infection`.
- [x] `PaintService.ClearAllPaint` выделен из `ResetForNewRound` - переиспользуется
  и в начале фазы пряток, и при переходе Hider → Seeker.
- [x] `CatchService.OnCatch(callback)` (новый хук, зеркало `OnAllCaught`) -
  вызывается при каждой поимке с `(hiderPlayer, seekerPlayer)`.
- [x] `PlayerRoleService.ConvertHiderToSeeker` (новый) - точечный перевод
  одного игрока, без пересчёта ролей всем.
- [x] `RoundManager.lua`: обработчик `OnCatch` реализует переход роли в
  Infection (снять позу → стереть покраску → сменить команду → вернуть
  скорость → перенести между `currentHiders`/`currentSeekers`).
- [x] Проверено и явно задокументировано: `CatchService.CountRemaining()`/
  `OnAllCaught` (условие конца раунда) **не потребовали изменений** - они уже
  считают по историческому факту поимки (`foundState`), а не по текущей
  команде игрока, поэтому корректно работают в обоих режимах без правок.
  ✔ Критерий: раунд в Infection заканчивается ровно тогда же, когда пойман
  последний исходный Hider - как и было задумано.
- [x] `RoundUIClient.lua`: подписка на смену `Team`, чтобы обновлять текст
  роли на HUD, если игрок был инфицирован посреди фазы Seeking (иначе HUD

  поймали! Теперь ты Искатель!" при получении `PlayerCaught` на себя.

## РАЗДЕЛ 4. Ручное тестирование (сценарии для Studio)

Прогнать каждый сценарий вручную и отметить результат:

- [ ] **2 игрока (минимум).** 1 Seeker, 1 Hider — раунд идёт, поимка работает.
- [ ] **10 игроков (максимум).** Роли раздаются (2–3 Seekers), не лагает.
- [ ] **Выход Seeker посреди раунда.** Игра не падает, раунд доигрывается.
- [ ] **Выход Hider посреди раунда.** Досрочное завершение считается корректно
  (см. фикс в Разделе 0).
- [ ] **Попытка рисовать во время позы.** Сервер отклоняет пакет мазков
  (`PaintService.onPaintStroke`, проверка `paintingBlocked`).
- [ ] **Попытка рисовать в фазе Seeking.** Сервер отклоняет (маскировка
  "заморожена" - `RoundManager.State ~= "Hiding"`).
- [ ] **Seeker пытается рисовать/красить.** Сервер отклоняет (роль не Hider).
- [ ] **Чернила заканчиваются.** При долгом непрерывном рисовании чернила
  доходят до 0, новые мазки перестают наноситься, но уже нанесённые остаются;
  чернила восстанавливаются со временем.
- [ ] **Свисток: автоматический.** Hider ничего не делает 45 секунд в фазе
  Seeking - звук проигрывается сам, таймер сбрасывается.
- [ ] **Свисток: ручной.** Hider жмёт "Свистнуть" раньше автоматического -
  звук проигрывается сразу, таймер сбрасывается на полный интервал.
- [ ] **Свисток пойманного Hider.** После поимки автосвисток для этого игрока
  больше не срабатывает.
- [ ] **Дальность свистка.** Игрок далеко (за пределами `RollOffMaxDistance`)
  не слышит звук, игрок рядом - слышит.
- [ ] **Поимка издалека (эксплойт).** По возможности проверить, что серверная
  проверка дистанции отклоняет поимку не вплотную.
- [ ] **Поимка через стену.** Искатель рядом с Hider, но между ними стена —
  сервер отклоняет (проверка line-of-sight, см. `DECISIONS.md` п.12).
- [ ] **Видимость подсказки "Поймать".** Два Hiders подходят друг к другу —
  подсказка над соседом НЕ появляется. Seeker подходит к Hider — подсказка
  появляется, без имени игрока.
- [ ] **Seeker пытается встать в позу.** Панель не видна / сервер отклоняет
  `RequestFreeze` (см. `DECISIONS.md` п.13).
- [ ] **Hider пытается сменить позу во время Seeking.** Панель скрыта,
  сервер отклоняет — поза остаётся такой, какой была на конец Hiding.
- [ ] **Выбор каждого из 4 пресетов позы.** Персонаж действительно принимает
  позу (после загрузки финальных анимаций), `HipHeight` меняется по
  множителю пресета, повторный клик по активной позе снимает её.
- [ ] **Переключение позы во время заморозки.** Выбрать "Присесть", затем
  не выходя из позы выбрать "Лечь" — старая анимация останавливается, новая
  проигрывается (не проигрываются обе одновременно).
- [ ] **Поза блокирует рисование.** Встать в любую позу — кнопка/панель
  кисти не даёт рисовать, сервер отклоняет `PaintStroke`.
- [ ] **Infection: поимка не выводит из игры.** Пойманный Hider мгновенно
  теряет позу и покраску, становится Seeker, может двигаться и ловить
  остальных Hiders.
- [ ] **Infection: HUD обновляется мгновенно.** У инфицированного игрока
  текст роли на HUD сразу меняется на "Искатель", показывается уведомление
  "Тебя поймали!".
- [ ] **Infection: условие конца раунда.** Раунд заканчивается, когда пойман
  последний исходный Hider (независимо от того, что все "бывшие Hiders"
  теперь Seekers).
- [ ] **Infection: очки за раунд.** Инфицированный игрок в результатах раунда
  показан с ролью Seeker, его очки включают и выживание-до-поимки, и (если
  успел) поимки после превращения.
- [ ] **Пустой сервер / 1 игрок.** Висит в Lobby, не стартует, не падает.
